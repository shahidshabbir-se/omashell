- Build an independent version of the Omarchy shell that can be installed on other Linux distributions without the Omarchy OS or its installed shell. Widgets may reproduce and adapt Omarchy behavior, but their runtime dependencies, assets, configuration, and integrations must not require Omarchy-specific files or commands; use portable alternatives or provide self-contained equivalents.
- When implementing or investigating an Omarchy feature, inspect `/usr/share/omarchy/shell` if available. Otherwise, clone the reference into a new temporary directory: `ref=$(mktemp -d) && git clone --depth 1 -b quattro https://github.com/omacom/omarchy/ "$ref/omarchy"`; the shell is in `$ref/omarchy/shell`. Treat it as reference source, not a runtime dependency. Check upstream licensing and preserve required attribution when adapting code.
- Run `./lint.sh` for QML and Bash syntax checks.
- `./launch.sh` starts the Quickshell shell in Hyprland. It selects the first Hyprland instance and uses the repository root as the `qs` import path. `--restart` stops the matching shell; even `--echo` can write an application desktop entry. Live testing can change desktop state and make network requests.
- Bar widget IDs must be registered in `modules/bar/WidgetRegistry.qml`; unknown IDs silently render nothing. Panel widgets also need wiring in `shell.qml`.
- Keep the visualizer bar count and input range in `config/Constants.qml` consistent with `modules/visualizer/cava.conf`.
